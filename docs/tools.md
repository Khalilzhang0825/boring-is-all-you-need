# SteadyAgent 2 Tools

All commands target Windows PowerShell 5.1.

```powershell
.\tools\install.ps1
.\tools\install.ps1 -Apply
.\tools\install.ps1 -Apply -ReplaceExistingWorkflow
.\tools\rollback.ps1 -ReceiptPath "<backup>\migration-receipt.json"
.\tools\rollback.ps1 -ReceiptPath "<backup>\migration-receipt.json" -Apply
.\tools\diagnose-install.ps1 -RequireHooksActive
.\tools\test-v2-migration.ps1
.\tools\test-agent-hooks.ps1
.\tools\test-git-checkpoint.ps1
.\tools\test-pre-commit.ps1
.\tools\skill-index.ps1
.\tools\skill-search.ps1 -Query "code review"
.\tools\test-skill-catalog.ps1
.\tools\test-protected-path-policy.ps1
.\tools\test-local-equivalence.ps1
.\tools\validate-release-readiness.ps1
```

`install.ps1` is dry-run by default. Custom roots are intended for tests and controlled deployments; the package source, target, Codex, managed-config, backup, and explicit Git-config paths must be pairwise disjoint (no equality or ancestor/descendant overlap). Injection parameters work only when `STEADYAGENT_TEST_MODE=1` and exist solely for isolated regression fixtures.

`rollback.ps1` is dry-run by default and accepts only an applied V2 receipt whose installed files, snapshots, and Git Hook path still match. Use only a receipt generated by your own installation.

`git-checkpoint.ps1` requires an empty real index and explicit repository-relative files. It stages in an isolated index, runs the pre-commit gate, rechecks exact scope, and publishes with compare-and-swap.

`diagnose-install.ps1` checks the installed package and exact active Codex matrix. `-RequireHooksActive` turns a missing managed config into failure.

`skill-index.ps1` reads the current Codex rollout, accepts only advertised skill entries, and publishes an immutable host/thread/prompt/digest-bound snapshot. `skill-search.ps1` verifies that identity before searching; custom catalogs require explicit fixture mode and never count as Live evidence.

`test-skill-catalog.ps1` is deterministic by default and uses an isolated synthetic `CODEX_HOME`. Set `STEADYAGENT_RUN_LIVE_CATALOG_CANARY=1` to append a check against the current Codex rollout; that optional canary requires `CODEX_THREAD_ID` and is not part of the repository or GitHub Actions release gate.

`test-local-equivalence.ps1` validates all 23 mappings, executes every bound semantic suite, performs an isolated real installation, compares the receipt with the exact 23 mapped plus 29 support destination allowlist, and first proves that source-hash, semantic-gate, and support-substitution mutations make the gate fail.
