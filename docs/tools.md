# SteadyAgent 2 Tools

All commands target Windows PowerShell 5.1.

```powershell
.\tools\install.ps1
.\tools\install.ps1 -Apply
.\tools\install.ps1 -Apply -ReplaceExistingWorkflow
.\tools\rollback.ps1 -ReceiptPath "<backup>\migration-receipt.json"
.\tools\rollback.ps1 -ReceiptPath "<backup>\migration-receipt.json" -Apply
.\tools\diagnose-install.ps1 -RequireHooksActive
.\tools\test-v2-migration.ps1
.\tools\test-agent-hooks.ps1
.\tools\test-git-checkpoint.ps1
.\tools\test-pre-commit.ps1
.\tools\validate-release-readiness.ps1
```

`install.ps1` is dry-run by default. Custom roots are intended for tests and controlled deployments. Injection parameters work only when `STEADYAGENT_TEST_MODE=1` and exist solely for isolated regression fixtures.

`rollback.ps1` is dry-run by default and accepts only an applied V2 receipt whose installed files, snapshots, and Git Hook path still match. Use only a receipt generated by your own installation.

`git-checkpoint.ps1` requires an empty real index and explicit repository-relative files. It stages in an isolated index, runs the pre-commit gate, rechecks exact scope, and publishes with compare-and-swap.

`diagnose-install.ps1` checks the installed package and exact active Codex matrix. `-RequireHooksActive` turns a missing managed config into failure.
